ⓘ Catatan kompatibilitas iPhone

WhatsApp Web dapat membatasi atau mengarahkan browser iPhone ke WhatsApp. Login QR di Safari tidak dijamin tersedia. Jika tidak bisa, gunakan aplikasi WhatsApp resmi atau buka WhatsApp Web dari komputer.

Akses cepat

Pasang di Home Screen

  1. Buka alamat aplikasi ini menggunakan Safari.
  2. Tekan tombol Share (ikon kotak dengan panah ke atas).
  3. Pilih Add to Home Screen / Tambahkan ke Layar Utama.
  4. Tekan Add. Ikon WA Web akan muncul di Home Screen.

Pemasangan membutuhkan alamat HTTPS. Membuka file HTML langsung dari penyimpanan tidak cukup untuk memasang PWA.
